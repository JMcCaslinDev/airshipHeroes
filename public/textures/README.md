# Textures Directory

This directory contains textures for the game blocks.

## Texture Files

- `lift_block.png`: Texture for Lift Blocks
- `armor_block.png`: Texture for Armor Blocks
- `engine_block.png`: Texture for Engine Blocks
- `cannon_block.png`: Texture for Cannon Blocks
- `steering_wheel_block.png`: Texture for Steering Wheel Blocks

## Adding New Textures

When adding new textures, make sure they are:
- Square (e.g., 256x256 pixels)
- Power of 2 dimensions (e.g., 128, 256, 512)
- PNG format with transparency if needed
- Optimized for web (compressed)
